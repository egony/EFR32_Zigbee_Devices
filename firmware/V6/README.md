### Прошивки для V6 на базе модулей RF-BM-MG24B2i

bootloader - прошивка загрузчика

zigbee_ncp - прошивка Zigbee координатора 

zigbee_router - прошивка Zigbee роутера (не проверял) 

openthread_rcp - прошивка OpenThread RCP (не проверял)

115200 и 230400 - скорости обмена чипа Zigbee с UART

В прошивках используется аппаратное управление потоком CTS/RTS.

egony_v6_nvm3_clear.gbl - прошивка для v6, которая стирает настройки сети (сброс до заводских параметров)

***

RF-BM-MG24B2i - старые прошивки для v6 с модулем RF-BM-MG24B2i

RF-BM-MG24B1 - прошивки для v6 с модулем RF-BM-MG24B1, модуль не поддерживается более
