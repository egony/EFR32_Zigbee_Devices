### Прошивки для V6 на базе модулей RF-BM-MG24B2i

Краткое описание:

**bootloader** - прошивки загрузчика

**zigbee_ncp** - прошивки Zigbee координатора 

**zigbee_router** - прошивки Zigbee роутера

**openthread_rcp** - прошивки OpenThread RCP

115200 и 230400 - скорости обмена чипа EFR32 с UART

В прошивках используется аппаратное управление потоком CTS/RTS (hw_flow). В прошивке роутера управление потоком не используется (no_flow).

**egony_v6_nvm3_clear.gbl** - прошивка для v6, которая стирает настройки сети (сброс до заводских параметров)
